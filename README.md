### Welcome to [Frobulator](https://frobulator.app)

Frobulator is a custom shell parser and scripting function library: Frobulate all the things!
Colorized line markers, prompts, progress feedback, checkpoints, and file, network and apt / dnf package helpers - **all while making redundant and complex code bits a thing of the past.**

Every function, argument and example is documented on [frobulator.app](https://frobulator.app).

---

### TL;DR

  - Install ↴
    - Run the script to install it to '~/.local/bin' - paste or type:
    ```
    curl -s -L get.frbltr.app > frobulator && bash frobulator
    ```

  - Source ↴
    - Load it at the top of a script - paste or type:
    ```
    . "${HOME}"/.local/bin/frobulator
    ```

  - Bootstrap ↴
    - Or start the script with the [bootstrap](bootstrap) header: it fetches the latest Frobulator, sources it and keeps it up to date.

  - Use ↴
    - Print a marker line - paste or type:
    ```
    frobulator.inf "Checking dependencies" "[ curl ]"
    ```

---

### Note:

The current set of assertions upon which Frobulator is built restricts its functionality to scripts exclusively, at least for the time being.
